# 올팍 겹침예보

올림픽공원 동시행사 혼잡 리스크 예보 서비스 — 2026 한국체육산업개발(주) 공공데이터 활용 경진대회 출품작

**데모:** 이 저장소의 `index.html` (Vercel 배포 주소는 제출 기획서 참조)

## 무엇을 하나요
- **대관 리스크 캘린더**: 2025년 실제 일정으로 날짜별 주차장 만차 위험을 예측하고 실제 기록과 비교(교차검증)
- **대관 시뮬레이터**: 날짜·공연장·인원·시작 시각을 넣으면 만차 확률(90% 범위), 퇴장 겹침 경보, ±7일 대체 날짜, 대관 검토 의견서
- **관람객 안내**: 서울시와 같은 4단계(여유·보통·약간 붐빔·붐빔) 국·영문 공지문 자동 생성
- **모델·데이터**: 검증 결과, 경보 기준별 성능, 원본 데이터 보정 내역, 지하철 보행 인파 검증

## 데이터
- 한국체육산업개발: 올림픽공원 2025 차량입출차·공연·날씨정보 등 연계 데이터, 주차장 혼잡도 정보, 공연정보, 대관정보, 입출차정보, 실시간 주차현황, 영문 공연정보
- 서울시: 지하철 역별 승하차 인원(교통카드), 실시간 도시데이터 / 기상청 단기예보

## 모델 요약
- L2 정규화 로지스틱 회귀 (주말·휴일, 동시 공연 수, 인원, 최고기온, 봄·가을)
- 5겹 교차검증 AUC 0.952, Brier 0.073 / 시간 순 검증 AUC 0.874
- 원본 연계 데이터에서 빠진 공연 15일을 공개 보도로 확인해 보정 (`analysis/corrections.csv`)

## 폴더
- `index.html` — 단일 파일 웹 데모 (모델 계수·검증 데이터 포함)
- `analysis/` — 모델 학습 코드, Firth 회귀 구현, 보정 내역, 지하철 검증 요약
